## Technique Details

### 1. Authority Hijack → Case Study Leverage
**Source:** @VibeMarketer_ borrows OpenAI engineer credibility ("an OpenAI engineer just showed...").
**Adaptation:** Never borrow — use own case studies. PRISME's authority comes from running the pipeline live, not referencing others.

### 2. Paradigm Framing
**Source:** @VibeMarketer_ describes Codex as "voice becomes a control layer" — abstraction above features.
**Adaptation:** Always present PRISME as a paradigm (prism metaphor), not a feature list. "One brief in, a spectrum of compliant content out."

### 3. Posture Shift Pitch
**Source:** "One person stops being the queue and starts directing it."
**Adaptation:** This IS the PRISME pitch. The client doesn't buy automation — they buy the shift from executor to director.

### 4. Branding by Acronym
**Source:** @iamsupersocks wraps standard PKM workflow into "méthode ACE" → sellable, searchable, proprietary.
**Adaptation:** PRISME follows the same pattern. French acronym, prism metaphor, no one else uses it in this context.

### 5. Visible Loop as Product
**Source:** @iamsupersocks shows Build → Capture → Extract → Content → Loop. Makes the invisible visible.
**Adaptation:** PRISME diagram (6 stages) serves the same purpose — workflow made tangible and sellable.

### 6. Sell a Role, Not an Agent
**Source:** Phil Goodwin (via @coreyganim) — "A small-business owner doesn't wake up wanting a VPS or LLM. They want someone to own work they're tired of doing."
**Adaptation:** Position PRISME agents as digital employees with job descriptions, not as tools with features.

### 7. Managed Layer = Real Product
**Source:** Phil Goodwin learned that one-time installs fail — clients stop using what he built. "The technology worked. The clients didn't."
**Adaptation:** PRISME's core revenue is the managed layer (adoption coaching + weekly reporting + ongoing optimization), not the install.

### 8. Anchor on Hours Saved
**Source:** @coreyganim — "Nobody pays $1,000 an hour for your time. They pay it to get theirs back."
**Adaptation:** All PRISME proposals anchor on client time recovered, never on our execution time.

### 9. Transparent Paid Pilot
**Source:** "I'm testing a managed-agent service. I'll install the agent, help you build workflows, and charge you a lower early-client price while I improve the offer."
**Adaptation:** For first 3-5 PRISME clients: transparent beta pricing + enhanced attention + case study rights.

### 10. Pricing Evolution Ladder
**Source:** $500 setup → $250/mo pilot → $1,500 setup + $500/mo → $2,000 setup + $1,000/mo target.
**Pattern:** Match price to proof. Early clients get lower price in exchange for testimonial + referral. Raise prices as fulfillment gets repeatable.

### 11. Assessment as Universal Entry Point
**Source:** @coreyganim's $999 assessment converts 50-60% to implementation.
**Adaptation:** Audit PRISME Live is the entry point for every prospect. But it's LIVE and AGENTIC, not a static PDF. Target 70%+ conversion.

### 12. Telegram Group Fulfillment
**Source:** Phil Goodwin creates a Telegram group with 3 members: client, agent, operator. Observable coaching.
**Adaptation:** PRISME can use the same pattern — client sees how the operator talks to agents, learns to delegate. Hermes Telegram integration makes this native.

### 13. Weekly Value Ledger
**Source:** Every task logged with: completed work, human time saved, $ value, tasks needing baseline. Weekly Friday report.
**Adaptation:** Implement as Hermes cron job. Agent logs all tasks → generates weekly report → sends to client. Makes the retainer visible and justifiable.

### 14. Marketing Agent Architecture
**Source:** Cody Schneider — 3 components: (1) unified data warehouse (ClickHouse), (2) autonomous decisions on cadence, (3) feedback loop of results.
**Adaptation:** Phase 2-3 of PRISME evolution. Airbyte → ClickHouse → LLM agent → publish/kill/analyze loop.

### 15. Entropy Injection
**Source:** Cody Schneider — agent stagnates → inject new DNA via competitor ads + transcripts.
**Adaptation:** PRISME étape E (Évaluation) + scout continuously scanning external signals prevents stagnation.

### 16. Swappable Graph Pipeline
**Source:** @shannholmberg Campaign Graph — each pipeline node (research→script→assets→render→delivery) is a replaceable skill.
**Adaptation:** PRISME IS a swappable graph. Each stage (P, R, I, S, M, E) is a Hermes skill that can be replaced without breaking the pipeline.

### 17. Model Routing Per Node
**Source:** Campaign Graph — different LLM model per pipeline stage based on task type.
**Adaptation:** Already in PRISME. GLM for reasoning, Claude for rewriting, Edge TTS for voice, etc.
