# Switzerland Import Rules Reference

## Free Trade Agreement: Suisse-Chine (ALE CH-CN)

- **In force since:** 1 July 2014
- **Effect:** Preferential tariffs (often 0%) on goods meeting rules of origin
- **Required document:** Formulaire F (Certificate of Origin FTA CH-CN)
  - Issued by: Chinese exporter via local Chamber of Commerce (CCPIT)
  - Without this document: MFN (Most Favored Nation) duty applies
  - Must be included in the original purchase contract

## Swiss VAT on Imports

| Rate | Applies to |
|---|---|
| **8.1%** | Standard rate (most goods) |
| 2.6% | Books, newspapers, food (some) |
| 3.8% | Accommodation services |

- VAT base: CIF value (CHF) + customs duty
- VAT is **recoverable** if the importer is VAT-registered in Switzerland
- Must advance the cash flow even if recoverable

## Key HS Codes for Import-Export

| Product | HS Code | CH Duty (MFN) | CH Duty (ALE CH-CN) |
|---|---|---|---|
| Chairs (wood) | 9401.61 | Low (~1-2%) | **0%** |
| Tables (wood) | 9403.30 | Low (~1-2%) | **0%** |
| Chairs (metal) | 9401.71 | Low | **0%** |
| Electronics (general) | 85xx | Varies | Partially reduced |
| Textiles | 50-63 | Varies (some high) | Partially reduced |

Always confirm HS code and current tariff on [tariff.admin.ch](https://www.tares.admin.ch) or with a Swiss customs broker.

## Import Process for Maritime Containers

```
1. Supplier loads container in China (FOB Shenzhen/Yantian)
2. Maritime transit: 28-35 days (Shenzhen → Rotterdam/Antwerp → Rhine → Basel)
3. Container arrives at Basel Rhine port
4. Customs broker files import declaration
5. Swiss customs assesses duty + VAT
6. Pay duty + VAT → customs releases container
7. Truck picks up: Basel → final destination
8. Unload at warehouse

Total door-to-door: 35-45 days typical
```

## Port of Entry: Basel

- Switzerland's primary maritime container port (Rhine river port)
- Well-connected to Rotterdam/Antwerp via Rhine barge
- THC unloading: ~CHF 350-450 per container
- Transit/customs broker: ~CHF 200-350
