# WhatsApp Transférable — Template

> Copier-coller ready pour diffusion parent-à-parent / communautaire.
> Validé sur Culture en Saveurs (juil. 2026).

## Règles de format

1. **Max 800 caractères** — WhatsApp tronque les longs messages sur mobile
2. **Emoji en début de ligne** — balise visuelle pour le scan rapide
3. **1 seul lien** — trop de liens = confusion, le parent ne clique sur aucun
4. **Auto-suffisant** — un parent doit avoir TOUTES les infos sans cliquer
5. **CTA explicite à la fin** — "Places limitées — réservez vite !"
6. **Tagline en signature** — renforce la marque au moment du transfert

## Diffusion strategy

Le message WhatsApp ne se poste pas — il se **transfère**. La stratégie :

1. **Envoyer à Linda** (la fondatrice) — elle transfère à son réseau
2. **Demander à Linda** de le partager dans : groupes WhatsApp parents d'école, groupes communautaires africains de Genève, groupes maison de quartier
3. **Joindre la vidéo courte** (le hook visuel) + le message texte (les infos)
4. **Le message doit être forwardable en 1 tap** — c'est pourquoi il doit être auto-suffisant sans la vidéo
