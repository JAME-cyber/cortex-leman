# YouTube Channel Metadata Template

Complete metadata pack for launching a YouTube channel. Fill in and copy directly to YouTube Studio.

## Channel Identity

```
Channel name: [NAME]
Handle: @[NAME][KEYWORD]    # e.g., @SankofaHistoire
Category: Éducation          # or Divertissement, Sciences, etc.
Country: [COUNTRY]
Language: [LANGUAGE]
```

## Description (≤1000 chars)

```
[NAME] — [TAGLINE]

[2-3 line mission statement]

Chaque épisode [KEY DIFFERENTIATOR]. Pas d'invention, pas d'exagération — juste [VALUE PROP].

[3-5 character names to seed SEO]

Nouvel épisode [FREQUENCY]. Abonne-toi pour ne rien manquer.

◆ [NAME] — "[MEANING]" ([ORIGIN])
```

```
Sankofa — L'histoire qu'on n'a pas racontée.

Nouvel épisode toutes les semaines. Abonne-toi pour ne rien manquer.

◆ Sankofa — "Reviens et récupère-le" (symbole Adinkra, peuple Akan)
```

## Keywords (≤500 chars, comma-separated)

```
[primary keyword], [secondary keyword], [character names], [genre], [topic modifiers], [related concepts]
```

## Video Titles (SEO-optimized pattern)

```
[CHARACTER NAME] : [HOOK/THEIR DEFINING ACT] | [CHANNEL NAME]
```

Examples:
```
Nzinga : La reine qui défia l'empire portugais pendant 40 ans | Sankofa
Mami Wata : La déesse des eaux vénérée dans le monde entier | Sankofa
Abla Pokou : Le sacrifice qui créa un peuple | Sankofa
```

**Pattern:** Name → colon → hook (action verb + stakes) → pipe → channel name. The hook should create curiosity, not just describe.


## Channel Settings Recommendations

| Setting | Value | Why |
|---------|-------|-----|
| Sub count visibility | Private | Avoids "0 subscriber" social proof drag |
| Feed recommendations | Enabled | Maximize discovery |
| Preferred videos for subs | Enabled | Pushes new uploads to sub feeds |
| Custom notifications | Enabled | Increases CTR on new videos |

## Launch Strategy

| Element | Recommendation | Rationale |
|---------|---------------|-----------|
| Min videos at launch | 3 | YouTube favors channels with content depth |
| Upload mode initial | Unlisted | QA before going public |
| Go-live sequence | Same day or 3 consecutive days | Concentrates initial momentum |
| Shorts | 2-3 per video (vertical cuts) | Drives discovery to long-form |
| Posting cadence | 1/week or 1/2weeks | Consistency > frequency |
