# LLM Prompt Delegation for Seedance/Hailuo Clip Generation

> Pattern: delegate Seedance/Hailuo prompt writing to an external LLM (GPT-5.6, Claude, etc.)
> instead of hand-crafting prompts from complex client feedback.

## When to use

Client feedback is complex, semantic, and multi-scene (e.g., "animatrice somalienne en tenue
traditionnelle avec voile", "orphelinat Cameroun vs atelier Genève multi-cultures"). The LLM excels
at translating natural-language client requests into structured cinematic prompts with all coherence
rules applied consistently.

## Two validated backends

### 1. GPT-5.6 via OpenRouter (pitfall #16, Jul 30, 2026)

Python script pattern: send raw client feedback + scene context to GPT-5.6, receive structured JSON.
Cost ~$0.05. Store output in `assets/phase2/gpt56_prompts.json`.

### 2. Claude via `hermes -z` (Aug 1, 2026)

Single shell command — no Python script needed:

```bash
hermes -z "your prompt-writing instruction here" \
  -m "anthropic/claude-haiku-4.5" \
  --provider openrouter
```

**Why `hermes -z` instead of `curl`**: Hermes masks API keys as `***` in the shell environment.
Direct `curl`/`python3 requests` calls to OpenRouter fail with HTTP 401. `hermes -z` handles
credentials internally and proxies the LLM call correctly (see pitfall #31).

**Model fallback strategy**: if the requested model returns 402 (credits exhausted), fall back to a
cheaper sibling. Validated chain: `anthropic/claude-fable-5` → 402 → `anthropic/claude-haiku-4.5`
→ equivalent quality output (see pitfall #32).

## System prompt template for Seedance prompt writing

```
You are an expert prompt engineer for Seedance 2.0 (AI video generation via kie.ai).
You write prompts in ENGLISH (Seedance understands English best).
Format: continuous descriptive cinematic prompt. 3-6 sentences max.

COHERENCE RULES (absolute priority):
- EXPLICIT ethnic diversity: "children of diverse African origins
  (North African, West African, East African, Central African)"
- Fewer children on screen (3-5 max), varied ages (6-12)
- Adult ethnicity MUST match the cultural origin of the activity
- Precise traditional attire when relevant
- "Culture en Saveurs" t-shirts with logo on children when visible
- No loops, natural movements

Palette: Terracotta, Ochre, Cocoa, Cream. Warm, bright atmosphere.
Style: photorealistic, cinematic, NOT Pixar/cartoon.
Format: 720x1280 (portrait) for vertical videos.
```

## Cost comparison

| Method | Cost | Setup effort |
|--------|------|-------------|
| GPT-5.6 via Python script | ~$0.05 | Medium (write script) |
| Claude haiku via `hermes -z` | ~$0.01 | Low (one shell command) |
| Hand-crafted prompts | $0 | High (manual iteration, error-prone) |

## Key rules

1. **Pass client-specified numbers through VERBATIM** (pitfall #17). If the client says "10
   children", the prompt says "10 children" — do not optimize.
2. **Enumerate each person** when the client specifies group composition (pitfall #20). List each
   child with physical descriptors, not "diverse children".
3. **Coherence rules are non-negotiable** — include them in the system prompt every time, even for
   follow-up single-clip requests.
4. **Cheapest capable model is sufficient** for prompt writing. The task is creative writing with
   constraints, not deep reasoning. Don't spend premium model credits on it.
