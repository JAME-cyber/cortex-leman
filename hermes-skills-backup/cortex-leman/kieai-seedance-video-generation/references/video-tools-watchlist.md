## Kamo-1 (par Kinetix / Philip Belhassen)

- **Status**: Open beta depuis déc 2025
- **Site**: kinetix.tech
- **Modèle**: 3D-conditioned AI video
- **USP**: Contrôle créatif (mouvement + caméra), pas juste qualité d'image
- **Input**: Performance réelle (motion corporel) → vidéo cinématique 3D
- **Différence avec Seedance**: Motion-to-video (pas text-to-video). Tu montres le mouvement, il génère avec ce contrôle exact.
- **Fit projets**:
  - **Baobab Kids** 🔥: Si le motion control permet animation cartoon 3D personnages
  - **Sankofa**: Secondaire — Seedance reste meilleur pour photoréalisme historique
- **Philip Belhassen**: CEO/VP Engineering Kinetix, 25+ ans (jeu vidéo, IA, web3). Lié au World AI Film Festival. Masterclass Scanderia 17 août 2026 (sujet = apps, pas vidéo). X @PBelhassen quasi inactif.
- **À surveiller**: Évolution API publique, pricing, options cartoon/stylisé
