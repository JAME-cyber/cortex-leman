## DEUX LIVRABLES À CODER

### LIVRABLE 1 — WEDGE VERTICAL "REVUE DE CONTRATS" (avocat)
Créer un module `/home/tars/cortex-leman-v5/core/verticals/contract_review/` :

**`__init__.py`**
**`models.py`** — Pydantic v2 :
- `ContractDocument` : document analysé (type : NDA/contrat commercial/CGV/contrat travail/etc., parties, juridiction, langue, texte/sections)
- `ContractIssue` : un problème détecté (clause abusive, déséquilibre, obligation manquante, droit applicable suspect, jurisdiction risk) avec sévérité, localisation (section/clause), base juridique, recommandation
- `ReviewResult` : résultat de revue = liste de ContractIssue + score de risque global + résumé + points à valider par l'avocat

**`reviewer.py`** — le moteur de revue (chaîne assistée, PAS décision automatique) :
- `review_contract(contract)` → ReviewResult
- Étapes : (1) extraction structure/clauses, (2) détection d'issues via un LLM (interface `LLMProvider` abstraite — pas d'appel en dur), (3) croisement avec une base de règles déterministes JsonLogic (clauses toujours risquées : droit applicable étranger, juridiction exclusive défavorable, pénalité disproportionnée, non-concurrence sans limite), (4) scoring de risque, (5) préparation des points pour arbitrage humain.
- JAMAIS rendre une décision finale — l'avocat arbitre. L'outil ASSISTE.

**`rules.json`** — règles JsonLogic déterministes pour contract_review (à brancher dans le Médiateur). 8-12 règles concrètes (ex : "clause de non-concurrence > 2 ans → freeze pour validation", "droit applicable hors UE/CH → flag risque", "pénalité > 10% du contrat → flag"). Format identique aux règles existantes (voir exemple comptable fourni).

**`prompts.yaml`** — system prompts pour le LLM (rôle "Juriste-Analyste Contractuel Lémanique", instructions, output schema, disclaimers). Style cohérent avec `core/agents/prompts/*.md` existants.

**`cli.py`** — `python -m core.verticals.contract_review "chemin/vers/contrat.pdf"` (ou .txt) → affiche le rapport de revue.

## CONTRAINTES DE STYLE (obligatoires)
- Python 3.12, type hints, Pydantic v2, async.
- Docstrings en français.
- LLM TOUJOURS derrière interface abstraite (le projet utilise déjà `core/integrations/llm/provider.py` — y faire référence, ne pas recoder).
- Règles JsonLogic au format EXACT des règles existantes (exemple fourni ci-dessous — champs : vertical, description, risk_appetite, rules[] avec id/name/severity/condition (JsonLogic)/action/message).

- Disclaimers légaux partout (secret professionnel Art. 321 CP, RGPD, "assiste, ne remplace pas l'expert").
