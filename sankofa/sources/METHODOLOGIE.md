# Sources — Exigences et méthodologie

## Règle d'or
Chaque personnage, chaque fait cité dans une vidéo DOIT être traçable à une source vérifiable.

## Hiérarchie des sources (de la plus à la moins fiable)

### Tier 1 — Académique (obligatoire pour faits historiques)
- Articles peer-reviewed (JSTOR, Cambridge, Oxford Academic)
- Livres d'universitaires (ed. universitaires)
- Thèses et mémoires soutenus
- Encyclopédies académiques (Britannica, Universalis)

### Tier 2 — Référence (acceptable pour contexte et récit)
- Wikipedia (avec sources citées dans l'article)
- Musées nationaux (Smithsonian, Quai Branly, British Museum)
- Instituts de recherche africains (IFAN Dakar, IRD)

### Tier 3 — Illustratif (contexte culturel uniquement)
- Articles de presse de qualité (Le Monde, BBC, RFI)
- Google Arts & Culture
- Sites culturels (FESPACO, UNESCO)

### Tier 4 — Interdit seul
- Blogs sans sources
- Vidéos YouTube sans bibliographie
- Réseaux sociaux

## Format de citation des sources
Chaque fiche personnage dans `/sources/` doit contenir :

```
## [Nom du personnage]
- **Type :** [Historique/Légendaire/Mythologique]
- **Sources Tier 1 :** [au moins 1 pour personnages historiques]
- **Sources Tier 2 :** [au moins 1]
- **Références complètes :** [format APA ou Chicago]
```

## Processus de vérification
1. Croiser au moins **2 sources indépendantes** pour tout fait clé
2. Distinguer explicitement mythe, légende et histoire dans le script
3. Citer la source à l'écran pendant la vidéo (slide "Sources")
4. Lier toutes les sources dans la description YouTube
