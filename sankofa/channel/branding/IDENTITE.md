# Sankofa — Identité de marque

## Le nom

**Sankofa** (prononcé SAN-KO-FA) — symbole Adinkra du peuple Akan (Ghana).
Signification twi : *"San kɔ fa"* = "Reviens et récupère-le".

Le concept : il n'est jamais trop tard pour retourner chercher dans le passé ce qui a été oublié. Le passé n'est pas un cimetière — c'est une ressource.

**Pourquoi pour cette chaîne :** Le nom EST la mission. On ne fait pas du nostalgie, on fait de la récupération active de récits effacés.

## Tagline

Version principale : **L'histoire qu'on n'a pas racontée.**
Version courte (intro/stinger) : **Retourne la chercher.**

## Le symbole

L'oiseau Sankofa : un oiseau vu de profil, le corps tourné vers l'avant, la tête ramenée vers l'arrière, un œuf dans le bec. L'œuf = le futur, extrait du passé.

**Usage :** watermark discret sur thumbnails, animation d'intro (3s), favicon, avatar chaîne.

## Palette de couleurs

| Rôle | Nom | Hex | Usage |
|------|-----|-----|-------|
| Primaire | Or Sankofa | `#E8A33D` | Logo, accents, texte highlight |
| Secondaire | Terre cuite | `#B5522E` | Backgrounds thumbnails, titres |
| Profond | Anthracite | `#1A1A1A` | Fond principal, texte fort |
| Clair | Sable | `#F4E8D0` | Background slides, texte sur fond sombre |

L'or doit dominer dans les thumbnails (brightness ≥0.95 sur le sujet principal, conformément aux standards QC).

## Typographie

- **Titres / Thumbnails :** Playfair Display (serif éditorial, autorité + élégance)
- **Corps / Slides :** Inter (sans-serif, lisibilité maximale)
- **Texte accentué :** Playfair Display Italic (citations, sources)

## Thumbnail — Template

Structure fixe pour reconnaissance de marque :
- Cadrage : portrait 9:16 (Shorts) ou 16:9 (long-form)
- Gauche : portrait illustré du personnage (illustration digitale, jamais photo stock)
- Droite : texte 3-4 mots max (Playfair Display Bold, or sur anthracite)
- Bas-gauche : oiseau Sankofa en watermark (10% opacité, or)
- Bord : trait fin or (#E8A33D, 2px)

## Intro / Stinger (3 secondes)

1. **0.0-1.0s :** Cercle de feu ambré apparaît, éclaboussures
2. **1.0-2.0s :** Le cercle se condense → silhouette d'oiseau Sankofa se forme
3. **2.0-3.0s :** L'oiseau prend un œuf, le mot "SANKOFA" apparaît en or (Playfair Display)
4. **Fade out** vers le contenu

Audio : note de kora (1 sec) + tintement grave.

## Voix off

- **Langue :** Français standard, accent neutre
- **Ton :** Narratif documentaire, pas professoral. Penser "Arte" pas "université"
- **TTS :** Edge TTS fr-FR-HenriNeural (déjà utilisé dans pipeline crypto)
- **Pacing :** phrases courtes, pauses marquées entre les actes narratifs

## Mentions obligatoires

- **Fin de vidéo :** slide Sources (liste académique, format APA condensé)
- **Description :** liens Wikipedia + références académiques
- **Disclaimer types de contenu :** "Histoire / Légende / Mythe" indiqué visuellement à l'écran au début de chaque segment concerné

## Ce que Sankofa n'est PAS

- Pas une chaîne afrocentriste militante
- Pas une chaîne de "découverte" sensationnaliste
- Pas une chaîne universitaire
- Pas un复原 historique ("reconstitution")

Sankofa = **récits fondés, narrés avec craft.**
