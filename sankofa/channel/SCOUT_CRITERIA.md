# Critères de sélection — Sujets vidéo

## Types de sujets éligibles
1. **Figures historiques** — rois, reines, guerriers, diplomates, résistants attestés
2. **Figures légendaires** — personnages de tradition orale avec possible noyau historique
3. **Mythologie** — dieux, esprits, héros culturels
4. **Civilisations/royaumes** — Mali, Songhaï, Grand Zimbabwe, Kongo, Benin, Axoum, Nubie
5. **Événements** — batailles, migrations, traités, résistances anti-coloniales

## Critères de pertinence (score /10)
| Critère | Poids | Note |
|---|---|---|
| Richesse narrative (potentiel storytelling) | /2 | Conflit, triomphe, tragédie, mystère |
| Attestation historique (sources disponibles) | /2 | Au moins 2 sources Tier 1-2 |
| Représentation féminine | /1 | Bonus si figure féminine forte |
| Impact culturel actuel | /2 | Symboles, noms, traditions vivantes |
| Originalité (peu traité par concurbes) | /1 | Éviter les sujets déjà sur-exploités |
| Potentiel visuel | /2 | Cartes, artefacts, reconstitutions possibles |

**Seuil GO :** ≥ 7/10

## Sujets prioritaires
1. Les 5 personnages initiaux (voir `sources/characters_initial.md`)
2. Extensions possibles : Sundiata Keita, Mansa Moussa, Behanzin, Samori Touré, Nehanda Charwe, Yaa Asantewaa, Ranavalona I

## Sujets à éviter
- Ceux sans sources vérifiables (Tier 1-2)
- Ceux déjà saturés sur YouTube français (sauf angle neuf)
